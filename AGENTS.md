# Repository workflow

- Keep changes local until the owner has manually tested them and explicitly asks to push or release. Passing automated checks is not publication approval.
- Do not push branches, merge pull requests, create or move remote tags, or publish releases without that approval for the current changes.
- Describe Throughline's own behavior in commit titles, pull requests and release notes. Keep private brainstorming and comparative design references out of public metadata.
- Preserve unrelated uncommitted work. This checkout may be shared with another assistant.
